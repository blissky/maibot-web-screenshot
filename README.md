# maibot-web-screenshot

MaiBot 网页全页截图插件。将“特定指令 => 网页链接”配置为列表，在群聊或私聊发送对应指令，即可将整个网页的 PNG 截图发送回当前聊天。

插件使用 MaiBot SDK 发送图片，并复用 MaiBot 运行环境已有的 Playwright 与 Chromium，不新增 Python 包，不适用于旧版 `src.plugin_system` 插件接口。

要求 Python 3.11+、MaiBot 1.3+（1.x）以及其运行环境自带的 `maibot-plugin-sdk` 2.8.2+（2.x）。Playwright 必须在插件 Runner 的 Python 环境中可导入；提供的 MaiBot 源码已将其列为主程序依赖。浏览器仍是截图的必要条件，离线且没有浏览器的环境无法直接截图。

## 安装

1. 将本仓库放到 MaiBot 的 `plugins/maibot-web-screenshot/` 目录，确保 `_manifest.json` 和 `plugin.py` 位于该目录的第一层。
2. 在 WebUI 加载插件或重启 MaiBot。首次加载会自动生成插件目录中的 `config.toml`，默认启用但不配置任何指令。
3. 在 WebUI 的“指令映射”中填写映射列表，或编辑生成的 `config.toml`，然后**重新加载插件**。

插件直接使用 MaiBot 运行环境已经安装的 Playwright 和 Chromium，不经过存在路由回调问题的 `render.html2png` 接口，不修改 MaiBot 源码。

插件通过 `config.get` 读取 `plugin_runtime.render` 下的启用状态、浏览器安装目录、可执行文件路径、调试地址和启动参数。优先使用配置的调试地址或可执行文件，否则查找配置目录中的已有 Chromium，再查找系统浏览器和 Playwright 默认缓存；相对目录按运行进程的工作目录解析，通常为 MaiBot 根目录。插件不修改 `PLAYWRIGHT_BROWSERS_PATH`，不额外下载浏览器；如果浏览器尚未准备好，请通过 MaiBot 准备缓存或配置可用的 `executable_path`。更新后需重新加载插件，以刷新 `config.get` 能力声明。

## 配置

沿用参考项目“订阅列表”的每行一组字符串列表方式，但只使用 `=>` 分隔指令和链接：

```toml
[plugin]
config_version = "1.1.0"
enabled = true

[commands]
match_mode = "contains"
mappings = [
    "/官网 => https://example.com",
    "/文档 => https://docs.mai-mai.org",
    "查看新闻 => https://example.com/news",
]
```

- 多条指令可指向不同链接，也可指向同一链接。
- `commands.match_mode` 可选 `contains`（包含匹配，默认）或 `exact`（完整匹配）；两种模式均区分大小写，不要求 `/` 前缀。
- 包含匹配：消息中出现配置指令即可触发，例如 `/官网`、`帮我看看 /官网`、`@机器人 /官网` 均可匹配 `/官网`。普通聊天中出现相同文字也会触发，建议使用明确的指令前缀以减少误触。
- 完整匹配：消息去除首尾空白后必须等于配置指令，例如 `/官网` 可匹配，但 `帮我看看 /官网`、`@机器人 /官网` 不匹配。
- 包含匹配命中多个指令时只执行消息中最先出现的一个；同一位置优先匹配较长指令。
- 指令中的正则特殊字符按普通文字处理。不支持重复指令、空指令、换行指令或非 HTTP/HTTPS 链接。
- 新增、删除、修改指令文字或切换匹配方式后必须重新加载插件，更新 Host 的匹配规则；仅修改已有指令对应的 URL 时，配置热更新即可生效。
- 禁用插件可在 WebUI 操作，或将 `plugin.enabled` 设为 `false`；重新启用后重新加载插件。

例如发送 `/官网`，机器人会截图该配置链接，而不是让用户临时指定 URL。成功后直接发送一张整页图片，不另发重复的成功消息。

两种模式都不要求 @ 机器人；默认的包含匹配也允许附带 @。已有配置缺少 `match_mode` 时会自动补齐为 `contains`，若要保留原来的完整匹配行为，请设置为 `exact` 并重新加载插件。

## 截图行为与限制

- MaiBot 运行环境中的 Chromium 真实打开链接，支持页面脚本、相对资源和重定向，而不是下载 HTML 后拼接渲染。
- 视口为 1280 × 720，等待页面 `load`、字体加载及额外 2 秒后，使用 `full_page=True` 截取整个文档，不只截第一屏；不再等待可能永远无法满足的 `networkidle`。无限滚动或依赖滚动触发加载的页面不保证包含所有动态内容。
- 同时只执行一个截图任务；繁忙时提示稍后再试，不无限排队。
- 一次截图任务（配置读取、浏览器启动、页面加载和截图）设定 45 秒总等待上限，单个页面加载阶段上限为 30 秒；超时会报告失败并清理浏览器资源，不自动下载浏览器。
- 页面使用插件创建的独立浏览器上下文，不读取个人浏览器 Cookie，不保存登录态。任务完成后关闭上下文和插件自己启动的浏览器；连接已有浏览器时仅释放本次上下文与连接，不关闭已有浏览器。
- 截图在插件内存中编码为 Base64，经 SDK 的 `send.image` 发送到触发指令的 `stream_id`，不在插件目录保存截图。
- 登录页、验证码、访问限制会显示浏览器实际看到的页面。无限滚动、虚拟列表、独立滚动容器不能保证全部业务内容都出现在文档中；本插件不提供登录或绕过站点限制功能。
- 聊天平台可能限制图片尺寸或体积。本插件不裁切整页图；发送失败时提示检查平台限制。

## 安全与排错

配置仅应由可信管理员维护：浏览器使用 MaiBot 所在机器的网络权限，配置内网或敏感页面可能将内容公开到聊天。只配置允许聊天参与者查看的页面，不使用带账号密码的 URL。

截图失败时检查：对应网页能否在运行机器打开、MaiBot 的浏览器渲染配置是否启用、Runner 环境中的 Playwright 和 Chromium 是否可用、浏览器缓存目录是否与 MaiBot 配置一致。HTTP 错误响应会直接失败；错误提示和插件自身日志不回显 URL、查询参数或浏览器异常详情。

运行时 `config.toml`、参考资料 `docs/`、虚拟环境、日志和测试产物均通过 `.gitignore` 排除。开发验证产生的截图、报告和临时脚本统一放在 `.test-artifacts/`，勿提交配置、凭据、聊天内容或 SSH 文件。
