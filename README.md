# maibot-web-screenshot

MaiBot 网页全页截图插件。将“特定指令 => 网页链接”配置为列表，在群聊或私聊发送对应指令，即可将整个网页的 PNG 截图发送回当前聊天。

插件只使用 MaiBot SDK 自带的浏览器渲染能力，不额外安装 Python 包，不适用于旧版 `src.plugin_system` 插件接口。

要求 Python 3.11+、MaiBot 1.3+（1.x）以及其运行环境自带的 `maibot-plugin-sdk` 2.8.2+（2.x）。浏览器仍是截图的必要条件，由 MaiBot 统一查找、下载与管理；离线且没有浏览器的环境无法直接截图。

## 安装

1. 将本仓库放到 MaiBot 的 `plugins/maibot-web-screenshot/` 目录，确保 `_manifest.json` 和 `plugin.py` 位于该目录的第一层。
2. 在 WebUI 加载插件或重启 MaiBot。首次加载会自动生成插件目录中的 `config.toml`，默认启用但不配置任何指令。
3. 在 WebUI 的“指令映射”中填写映射列表，或编辑生成的 `config.toml`，然后**重新加载插件**。

插件复用 MaiBot 的 `render.html2png`。请在 MaiBot 的“插件运行时 / 浏览器渲染”配置中保持渲染能力启用；找不到 Chromium 时保持“自动下载 Chromium”开启即可。首次使用可能需要下载浏览器，下载超时和安装目录由 MaiBot 统一管理，无需为本插件单独安装 Python 依赖。

## 配置

沿用参考项目“订阅列表”的每行一组字符串列表方式，但只使用 `=>` 分隔指令和链接：

```toml
[plugin]
config_version = "1.0.0"
enabled = true

[commands]
mappings = [
    "/官网 => https://example.com",
    "/文档 => https://docs.mai-mai.org",
    "查看新闻 => https://example.com/news",
]
```

- 多条指令可指向不同链接，也可指向同一链接。
- 指令按完整文本、区分大小写匹配，忽略消息首尾空白，不要求 `/` 前缀；不会匹配普通聊天中的部分词语。
- 指令中的正则特殊字符按普通文字处理。不支持重复指令、空指令、换行指令或非 HTTP/HTTPS 链接。
- 新增、删除或修改指令文字后必须重新加载插件，更新 Host 的匹配规则；仅修改已有指令对应的 URL 时，配置热更新即可生效。
- 禁用插件可在 WebUI 操作，或将 `plugin.enabled` 设为 `false`；重新启用后重新加载插件。

例如发送 `/官网`，机器人会截图该配置链接，而不是让用户临时指定 URL。成功后直接发送一张整页图片，不另发重复的成功消息。

## 截图行为与限制

- MaiBot 内置 Chromium 真实打开链接，支持页面脚本、相对资源和重定向，而不是下载 HTML 后拼接渲染。
- 视口为 1280 × 720，等待网络空闲后使用 `full_page=True` 截取整个文档，不只截第一屏；无限滚动或依赖滚动触发加载的页面不保证包含所有动态内容。
- 同时只执行一个截图任务；繁忙时提示稍后再试，不无限排队。
- 一次渲染能力调用（包括等待浏览器准备）的总等待上限为 45 秒，单个页面加载阶段上限为 30 秒；超时会报告失败。首次浏览器下载若未完成，可待 MaiBot 准备完成后重试。
- 页面使用 MaiBot 渲染服务的独立上下文，不读取个人浏览器 Cookie，不保存登录态。
- 截图由 MaiBot 渲染服务直接以 Base64 返回，经 SDK 的 `send.image` 发送到触发指令的 `stream_id`，不在插件目录保存截图。
- 登录页、验证码、访问限制会显示浏览器实际看到的页面。无限滚动、虚拟列表、独立滚动容器不能保证全部业务内容都出现在文档中；本插件不提供登录或绕过站点限制功能。
- 聊天平台可能限制图片尺寸或体积。本插件不裁切整页图；发送失败时提示检查平台限制。

## 安全与排错

配置仅应由可信管理员维护：浏览器使用 MaiBot 所在机器的网络权限，配置内网或敏感页面可能将内容公开到聊天。只配置允许聊天参与者查看的页面，不使用带账号密码的 URL。

截图失败时检查：对应网页能否在运行机器打开、MaiBot 浏览器渲染能力是否启用、Chromium 是否下载完成、页面是否持续保持网络活动。内置接口不提供 HTTP 状态码，站点错误页面也可能按实际显示内容截图；错误提示和插件自身日志不回显 URL、查询参数或浏览器异常详情。

运行时 `config.toml`、参考资料 `docs/`、虚拟环境、日志和测试产物均通过 `.gitignore` 排除。开发验证产生的截图、报告和临时脚本统一放在 `.test-artifacts/`，勿提交配置、凭据、聊天内容或 SSH 文件。
